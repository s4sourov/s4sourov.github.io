# Sourov Datta | Personal Portfolio

A minimal, futuristic personal portfolio website built with pure **HTML, CSS and JavaScript**. This is my first solo project.

## About Me

I'm an IT student and photographer based in Sydney, Australia, originally from Habiganj, Sylhet. I love capturing nature, exploring new places and playing games (sometimes with AI by my side).

> Chasing light through a lens, building things with code.

## Features

- Camera viewfinder style hero with a focus-pull animation
- Animated star field background
- Floating glass navigation bar with scroll tracking and a progress line
- Animated project previews
- Scroll-animated education timeline
- Live Sydney clock
- One-click email copy button
- Fully responsive and respects reduced-motion settings

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Syne and Manrope)
